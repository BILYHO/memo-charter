# 安装手册 · 10 分钟接入 Claude Code

## 0. 前置

- Claude Code（需支持 SessionStart hook，2025 年中以后的版本都支持）
- Python ≥ 3.8（终端跑 `python --version` 或 `python3 --version` 能出结果即可）
- Windows 用户：需要 Git for Windows（自带 `bash.exe`）

## 1. 放到固定位置

macOS / Linux：

```bash
mv memo-charter ~/memo-charter
chmod +x ~/memo-charter/hooks/session-start.sh
```

Windows（PowerShell）：

```powershell
Move-Item memo-charter $env:USERPROFILE\memo-charter
```

路径一旦定下就别再挪，hook 配置里要写绝对路径。

## 2. 填画像

打开 `distill/one-pager.md`，把所有 `<…>` 占位换成你的真实偏好。只填你真在意的，每条一行。
不确定写什么就先保留默认值，用一周后回来改。

## 3. 接 hook

打开 `~/.claude/settings.json`（没有就新建），在 `hooks` 里加一段。

macOS / Linux：

```json
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "startup|clear|compact",
        "hooks": [
          {
            "type": "command",
            "command": "bash \"$HOME/memo-charter/hooks/session-start.sh\"",
            "statusMessage": "注入协作规则..."
          }
        ]
      }
    ]
  }
}
```

Windows（把 Git 安装目录和用户名换成你的，注意 JSON 里反斜杠要写两个）：

```json
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "startup|clear|compact",
        "hooks": [
          {
            "type": "command",
            "command": "& \"C:\\Program Files\\Git\\bin\\bash.exe\" \"C:/Users/<你的用户名>/memo-charter/hooks/session-start.sh\"",
            "shell": "powershell",
            "statusMessage": "注入协作规则..."
          }
        ]
      }
    ]
  }
}
```

已有 `hooks` 段的，把 `SessionStart` 数组合并进去即可。

## 4. 验证（别跳过）

先在终端直接跑一次，确认输出是一段 JSON 而不是报错：

```bash
bash ~/memo-charter/hooks/session-start.sh | head -c 300
```

看到 `{"hookSpecificOutput": {"hookEventName": "SessionStart", "additionalContext": "<memo-charter-context>` 开头即正常。
如果看到 `⚠️ 注入降级`，按提示补文件或装 Python。

然后新开一个 Claude Code 会话，问：

> 你知道我是谁吗？我有哪几条红线？

它能复述 `one-pager.md` 的内容和 4 条红线，就接好了。

## 5. 全局 CLAUDE.md 只留一行

如果你原来在 `~/.claude/CLAUDE.md` 里堆了很多规则，建议搬进 `rules/`，CLAUDE.md 只留一句：

```
规则由 ~/memo-charter 统一管理，SessionStart hook 自动注入；若上下文里没有 <memo-charter-context> 块，先读 ~/memo-charter/distill/top-rules.md 再开始。
```

为什么：两处写规则必然漂移；而且 CLAUDE.md 每次都全量进上下文，不如 hook 省 token。

## 常见问题

**hook 跑了但模型好像没读到？**
在会话里直接问"上下文里有没有 memo-charter-context 块"。没有的话，多半是路径写错或 bash 不在 PATH，用第 4 步的命令在终端复现。

**Windows 中文乱码 / 注入为空？**
脚本已设 `PYTHONIOENCODING=utf-8`。仍异常时确认 `bash.exe` 是 Git 自带的那个，不是 WSL 的。

**想换 Cursor / Codex 用？**
`distill/` 下两份 Markdown 是纯文本，直接作为那些工具的 rules 文件引用即可；hook 是 Claude Code 专属。
